# 効果音と使用場面

- `player-normal-attack.mp3`: 味方の通常攻撃
- `special-move-hit.mp3`: 必殺技が命中した時
- `healing-action.mp3`: HP・SPを回復する固有技または必殺技
- `stage-clear-level-up.mp3`: ステージクリア報酬で1体以上がレベルアップした時
- `enemy-normal-attack.mp3`: 敵・野生・中立キャラクターの通常攻撃
- `battle-scene-transition.mp3`: 通常または必殺技の戦闘カットインへ切り替わる時

ファイル名は、ゲーム内の使用場面が分かる半角英数字とハイフンで統一しています。
