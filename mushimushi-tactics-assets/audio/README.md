# 音声素材の置き場所

ゲームへ追加する音声ファイルは、用途ごとに次のフォルダへ入れてください。

- `bgm/`: タイトル、作戦基地、戦闘などのBGM
- `sfx/`: 攻撃、命中、回復、決定などの短い効果音

## 推奨形式

- 公開用は `.mp3` または `.ogg`
- ファイル名は半角英数字とハイフンを使用（例: `battle-main.mp3`）
- BGMは曲の前後に長い無音を入れず、ループしてもつながる状態を推奨
- 効果音は必要な音だけを短く切り出し、音割れしない音量を推奨

音声をこのフォルダへ置いただけではゲーム中に再生されません。追加後、`index.html`で再生場面と音量を設定する必要があります。

自作音源、または無料利用・改変・GitHub Pagesでの公開が許可されていると確認できた音源だけを使用してください。外部音源は、配布元URL・作者名・利用条件も記録してください。
