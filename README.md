# 森の英雄伝 ～小さな世界の大決戦～

![森の英雄伝のタイトル画像](mushimushi-tactics-assets/opening-hero-v2.webp)

昆虫や森の生き物で3体の部隊を編成し、地形と連携を使って戦うターン制タクティカルゲームです。本編2章・25ステージ＋別枠の特別作戦、仲間35種類、ステージ別限定報酬、キャラクター別装備、装備合成、木の実商店、レベル習得型の必殺技、セーブ、中断再開、ゲームコントローラー操作に対応しています。

## 今すぐ遊ぶ

[ブラウザーで「森の英雄伝」を開く](https://yoshimaru-kun.github.io/morino-eiyuden/)

## 遊び方

上の公開ページを開き、画面をクリックするかキーを押すと音が有効になります。PCの横長画面を推奨します。

- 方向キー / WASD: カーソル移動
- Enter / Aボタン: 決定
- Esc / Bボタン: 戻る・取り消し
- 戦闘の移動・攻撃・必殺技選択：画面内の「戻る」、またはマウスの戻るサイドボタンでも取り消し可能
- M / Yボタン: 全体マップ
- R / RBボタン: 危険範囲
- O: オプション
- Q: 音のON/OFF

初回は練習バトルから始まります。漢字には子供向けのふりがなを表示します。

## セーブ

進行状況はブラウザーの `localStorage` に保存します。サーバーへセーブデータを送信する処理はありません。端末やブラウザーを変更する前に、作戦基地の「セーブを書き出す」を利用してください。

呼び名に本名・住所・電話番号などを入力しないでください。書き出したセーブファイルにも呼び名が含まれます。

## 収録内容

- 第1章15ステージ＋高難度の第2章10ステージ。第1章ステージ10クリア後に解放される別枠の特別作戦は、本編の番号とエンディング条件に含みません
- 仲間35種類。第2章ではヤエヤマサソリ、オオミズアオ、カタツムリ、ヘビトンボ、オオコノハムシが加入候補として登場
- 通常作戦・特別作戦のクリアごとに、その作戦限定のキャラクターまたは装備品を各50％で獲得。初回・周回とも木の実コインも獲得
- ステージ選択画面に、1体あたりのクリア経験値・森のしずく・木の実コインを「10～14」のような範囲で表示。実際の獲得量も表示範囲内で抽選
- 森のしずくは、ほかのアイテムと統一した透過背景のアニメ調専用画像で、所持数・強化費用・作戦報酬に表示
- 初期3体はステージ1〜3へ1体ずつ固定。第1章のキャラクターと装備品は従来の割り当てを維持し、第2章は新しい仲間5体を各2ステージの候補として追加
- クリアEXPは出撃した3体だけが獲得。結果画面に3体の画像、獲得量、レベル、動くEXPバーを表示
- 同じキャラクターは「同族の心得」が最大20段階まで上がり、HP・攻撃・防御・SPを強化
- 森のしずくによる能力強化は各項目10段階。6段階目以降は上昇量を抑え、後半ほど費用が増加
- 作戦基地の部隊一覧・生き物図鑑は、図鑑枠とカード全面を使った大きな画像表示
- 基地で各キャラクターの主な登場作戦・入手場所・入手方法を確認可能。未加入キャラクターにも案内を表示
- アニメ調の専用画像を持つ装備品16種。キャラクターごとに1個を装備でき、同じ品は所持数だけ別々の仲間へ配布可能
- 同名のLv.1装備と木の実コインを使う合成で、選んだ装備をLv.5まで強化可能。合成しなければ装備品の個数として残る
- 木の実商店で回復・SP回復・攻撃強化・状態異常治療アイテムと装備品を購入可能。一覧で商品を選ぶと、大きな画像・効果・所持数・価格を表示する専用の商品画面へ切り替わる。消費アイテムは5種。治療薬2種は同梱の装備品画像を再利用
- 対応する必殺技の命中で毒・麻痺・攻撃低下・防御低下・命中低下を付与。毒は3ラウンド、ほかは2ラウンドで自然回復。同じ異常は重複せず残り時間を更新
- 毒はラウンド終了時に最大HPの8％ダメージ。麻痺は移動力半減・反撃不可（技やアイテムは使用可能）。攻撃・防御低下は各25％、命中低下は20ポイント
- 花蜜シャワー・水辺の恵み・七星のおまもり・花風の舞・月光の粉と回復系必殺技に、範囲内の状態異常をすべて治す効果を追加。HP満タンでも治療可能
- 解毒の花蜜（30コイン）は自分の毒、清めのしずく薬（60コイン）は自分の全状態異常を治療。対象の異常がなければ消費しません。状態異常と残り時間は中断セーブでも維持し、旧セーブも読み込み可能
- 出撃前に消費アイテムを合計3個まで選択。戦闘では持ち込んだ分だけを1行動として使用でき、中断再開でも残数を維持
- 全35キャラクターに必殺技5個。Lv.1・15・25・35・45で習得し、基地から未習得技も確認可能
- 固有技は1ステージにつき各キャラクター3回まで使用可能。行動メニューに選択中キャラクターの残り回数を表示
- 固有技はLv.10・25・40で進化。各段階で2つから選び、基地で何度でも選び直せるため、1体につき8通りの育成が可能
- ステージ9にタランチュラ、ステージ10にアブラゼミが登場
- レベル上限70。第2章はおすすめLv.50～70、敵Lv.49～68で段階的に難しくなります
- 通常・やさしい難易度
- 敗北時の同条件再戦
- BGM7曲と一部の効果音をWeb Audio APIで端末内合成。通常攻撃・必殺技命中・回復・戦闘突入・ステージクリア時のレベルアップには同梱MP3を使用し、合成音・MP3・BGMの出力基準を揃えて再生
- 外部API、広告、解析、ログイン、課金なし

詳しい操作と仕様は [はじめに.txt](はじめに.txt)、画像・権利・データの説明は [素材と公開について.html](素材と公開について.html) を確認してください。
