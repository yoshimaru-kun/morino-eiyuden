# 森の英雄伝 ～小さな世界の大決戦～

![森の英雄伝のタイトル画像](mushimushi-tactics-assets/opening-hero-v2.webp)

昆虫や森の生き物で3体の部隊を編成し、地形と連携を使って戦うターン制タクティカルゲームです。全10ステージ＋特別作戦、仲間24種類、ステージ別限定報酬、同キャラクター強化、森の秘宝、レベル習得型の必殺技、セーブ、中断再開、ゲームコントローラー操作に対応しています。

## 今すぐ遊ぶ

[ブラウザーで「森の英雄伝」を開く](https://yoshimaru-kun.github.io/morino-eiyuden/)

## 遊び方

上の公開ページを開き、画面をクリックするかキーを押すと音が有効になります。PCの横長画面を推奨します。

- 方向キー / WASD: カーソル移動
- Enter / Aボタン: 決定
- Esc / Bボタン: 戻る・取り消し
- M / Yボタン: 全体マップ
- R / RBボタン: 危険範囲
- O: オプション
- Q: 音のON/OFF

初回は練習バトルから始まります。漢字には子供向けのふりがなを表示します。

## セーブ

進行状況はブラウザーの `localStorage` に保存します。サーバーへセーブデータを送信する処理はありません。端末やブラウザーを変更する前に、作戦基地の「セーブを書き出す」を利用してください。

呼び名に本名・住所・電話番号などを入力しないでください。書き出したセーブファイルにも呼び名が含まれます。

## 収録内容

- 全10ステージ＋本編クリア後の特別作戦
- 仲間24種類。通常作戦・特別作戦のクリアごとに、そのステージ限定のキャラクターまたはアイテムを各50％で獲得
- 初期3体もステージ1〜3へ1体ずつ固定し、各キャラクターと秘宝は割り当てられたステージ以外からは出現しません
- クリアEXPは出撃した3体だけが獲得。結果画面に3体の画像、獲得量、レベル、動くEXPバーを表示
- 同じキャラクターは「同族の心得」が最大20段階まで上がり、HP・攻撃・防御・SPを強化
- 森のしずくによる能力強化は各項目10段階。6段階目以降は上昇量を抑え、後半ほど費用が増加
- 作戦基地の部隊一覧・生き物図鑑は、図鑑枠とカード全面を使った大きな画像表示
- 基地で各キャラクターの主な登場作戦・入手場所・入手方法を確認可能。未加入キャラクターにも案内を表示
- 装備できるアイテム「森の秘宝」11種。重複するとRank 5まで強化
- 全24キャラクターに必殺技5個。Lv.1・15・25・35・45で習得し、基地から未習得技も確認可能
- ステージ9にタランチュラ、ステージ10にアブラゼミが登場
- レベル上限50
- 通常・やさしい難易度
- 敗北時の同条件再戦
- BGM7曲と効果音をWeb Audio APIで端末内合成
- 外部API、広告、解析、ログイン、課金なし

詳しい操作と仕様は [はじめに.txt](はじめに.txt)、画像・権利・データの説明は [素材と公開について.html](素材と公開について.html) を確認してください。
