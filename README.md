# 森の英雄伝 ～小さな世界の大決戦～

![森の英雄伝のタイトル画像](mushimushi-tactics-assets/opening-hero-v2.webp)

昆虫や森の生き物で3体の部隊を編成し、地形と連携を使って戦うターン制タクティカルゲームです。全8ステージ、仲間18種類、練習バトル、レベル・強化、セーブ、中断再開、ゲームコントローラー操作に対応しています。

## 遊び方

公開ページの `index.html` を開き、画面をクリックするかキーを押すと音が有効になります。PCの横長画面を推奨します。

- 方向キー / WASD: カーソル移動
- Enter / Aボタン: 決定
- Esc / Bボタン: 戻る・取り消し
- M / Yボタン: 全体マップ
- R / RBボタン: 危険範囲
- O: オプション
- Q: 音のON/OFF

初回は練習バトルから始まります。漢字には子供向けのふりがなを表示します。

## セーブ

進行状況はブラウザーの `localStorage` に保存します。サーバーへセーブデータを送信する処理はありません。端末やブラウザーを変更する前に、作戦基地の「セーブを書き出す」を利用してください。

呼び名に本名・住所・電話番号などを入力しないでください。書き出したセーブファイルにも呼び名が含まれます。

## 収録内容

- 全8ステージ
- 仲間18種類、1回の勝利につき1体を選んで加入
- レベル上限50
- 通常・やさしい難易度
- 敗北時の同条件再戦
- BGM7曲と効果音をWeb Audio APIで端末内合成
- 外部API、広告、解析、ログイン、課金なし

詳しい操作と仕様は [はじめに.txt](はじめに.txt)、画像・権利・データの説明は [素材と公開について.html](素材と公開について.html) を確認してください。

## 動作環境

現在のChrome、Edge、Firefoxなど、CanvasとWeb Audio APIに対応したブラウザーを想定しています。スマートフォンでも開けますが、PCとキーボードまたはゲームコントローラーを推奨します。
